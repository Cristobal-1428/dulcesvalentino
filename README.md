# Dulces Valentino · Pastelería de tortas

Página web de una pastelería artesanal de tortas. Una sola página, sin dependencias.

## Cómo abrirla
1. Abre la carpeta en VS Code (Archivo → Abrir carpeta).
2. Haz doble clic en `index.html` para verla en tu navegador,
   o instala la extensión **Live Server** y haz clic derecho sobre
   `index.html` → "Open with Live Server".

## Estructura
- `index.html` — toda la página (HTML, CSS y JS en un solo archivo).

## Qué puedes cambiar fácil
- Nombre de la pastelería: busca "Dulces Valentino".
- Colores: variables al inicio del `<style>` (`:root`).
- Tortas y precios: sección `<!-- TORTAS -->`.
- Datos de contacto: sección `<!-- ENCARGO -->`.
